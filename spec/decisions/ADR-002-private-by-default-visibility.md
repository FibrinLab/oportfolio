# ADR-002: Portfolio narrative is private by default

Status: Accepted as product baseline; controller approval required  
Date: 12 August 2026

## Context

Reflections and supervisor feedback are identifiable professional-development records and can incidentally include highly personal or third-party information. Faculty needs operational oversight, but that does not require routine access to every narrative.

## Decision

New evidence, reflection and SWOT content defaults to fellow-only. Sharing uses explicit audience labels. Supervisors/faculty only read content shared to them or copied through a previewed formal-review snapshot. Tenant administrators have metadata/configuration access, not routine content access. Any exceptional access is separately approved, time-bound and audited.

## Consequences

- Search, counts, notifications, analytics, files and exports must enforce visibility—not only detail pages.
- Faculty dashboards rely mainly on operational metadata and permitted aggregates.
- Formal review preparation must clearly copy selected material into the signed record.
- Some programmes may choose a narrower set of audiences, but cannot silently broaden existing content.
